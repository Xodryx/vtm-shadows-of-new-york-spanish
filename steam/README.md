# Guida Steam

La guida Steam si compone di sezioni, ognuna con titolo e corpo, aggiunte una alla volta
con **Aggiungi una sezione**. I file in `sections/` contengono **solo il corpo**; il titolo
si scrive a mano, prendendolo da questa tabella, in quest'ordine:

| # | Titolo della sezione | File da incollare nel corpo |
|---|---|---|
| 1 | Qué es | `sections/01-what-it-is.txt` |
| 2 | Antes de empezar | `sections/02-before-you-start.txt` |
| 3 | Instalación | `sections/03-installation.txt` |
| 4 | Si algo no funciona | `sections/04-troubleshooting.txt` |
| 5 | Desinstalación | `sections/05-uninstall.txt` |
| 6 | Cómo está hecha la traducción | `sections/06-how-its-made.txt` |
| 7 | Avisar de un error | `sections/07-reporting.txt` |
| 8 | Enlaces | `sections/08-links.txt` |

## Informazioni di base

| Campo | Valore |
|---|---|
| Titolo | `Traducción completa al español - Complete Spanish translation` |
| Categorie | Creazione di mod o configurazione; Guide |
| Lingua | Spagnolo |

Descrizione breve:

    Cómo instalar la traducción completa al español del juego: las 5699 líneas, el diccionario, los nombres y las misiones. No modifica ningún archivo del juego.

## Immagini

- **Anteprima della guida:** uno screenshot del gioco in spagnolo con una battuta
  leggibile.
- **Dentro la sezione Instalación:** il menu delle opzioni con **Español** visibile.

## A ogni nuova versione

Il numero di battute compare in `01-what-it-is.txt`, `04-troubleshooting.txt`,
`07-reporting.txt` e nella descrizione breve.
